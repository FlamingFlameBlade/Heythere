# Math Game

## Description
Math Game allows the user to test their skills in different areas of math and level up through correct answers.​

## Features
- Experience system that increases are correct answers are chosen
- Multiple math areas to choose from

## Instructions
Install Android Studios and complete the following:
```
1. Open Android Studios.
2. Click get from VCS.
3. Paste the URL of the repository.
4. Click Clone.
```
